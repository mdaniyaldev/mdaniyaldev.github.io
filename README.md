# Muhammad Daniyal Portfolio

A clean multi-page HTML/CSS portfolio starter tailored from your resume.

## Pages
- Home (`index.html`)
- About (`about.html`)
- Experience (`experience.html`)
- Projects (`projects.html`)
- Skills (`skills.html`)
- Certifications (`certifications.html`)
- Contact (`contact.html`)

## How to use
1. Upload these files to your GitHub repository.
2. Enable GitHub Pages in **Settings → Pages**.
3. Select the default branch and root folder.
4. Visit your Pages URL.

## Customize
- Replace the initials logo with your full name or a personal mark.
- Add project screenshots inside the project cards if you want.
- Add your LinkedIn URL on the Contact page.
- If you want a resume download button, add your PDF to the repo and link it.
